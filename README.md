# ドンピシャ！ビートパレード

リズム天国シリーズにインスパイアされた、ブラウザで動く1ボタンリズムゲームです。
外部素材・ライブラリなし。音はすべて Web Audio API でリアルタイム合成（7ジャンルのBGMを自動作曲）。`index.html` をブラウザで開くだけで遊べます。

## バージョン切り替え

セレクト画面右上の **📼 ボタン**で、ゲームのバージョンをいつでも切り替えられます（設定はセーブデータとは別に保存され、🗑 で消しても残ります。進行状況・記録は両バージョン共通です）。

| | 📼 初期バージョン | 📼 Ver. 1（最新） |
|---|---|---|
| 内容 | ミニゲーム（ステージ1〜15）＋リミックス1〜20、裏モード | すべて |
| 操作 | スペース / J / F / クリック / タップ のみ | アローキー・WASD・長押しあり |
| タイミングレーン | なし（ON/OFFもなし） | あり（Lキーで切替） |
| 2人プレイ | なし | 協力・対戦・専用40種・アローゲーム |
| そのほか | — | パーフェクトキャンペーン、ナイトモード、エンドレス |

初期バージョンでは長押しノーツは普通のノーツとして出題され、アローキー/WASDは入力として使えません。

## 遊び方

- **操作はワンボタン**: スペースキー / アローキー(↑↓←→) / J / F / クリック / タップ
- **アローゲーム（20種）** では ↑↓←→ がそれぞれ別のアクションになります。ノーツに付いた矢印と同じ方向のキーでしか取れず、スペースや違う方向だと「ほうこう ちがい」（おてつき扱い）。1人モードではWASDでも方向を入力でき、画面右の方向パッドをタップしても入力できます。それ以外のゲームではアローキー/WASDは従来どおり汎用ボタンです。
  - 方向で反応: ブロックマスター（4方向から飛来）／スターシューター４／もぐら4ほうこう（💣は押すな）／しゅりけんにんじゃ（出現タイミングがまちまち・レーン非表示）／どうぶつのこえ（鳴き声の高さだけで方向を聞き分ける・レーン非表示）
  - 順番・記憶: ダンスレッスン（覚えて再現）／さかさまエコー（逆順で再現）／かがみダンス（反対方向を押す）／かんばんタイピング（4つを読んで8分で入力）／かざぐるま（回転の向きに4方向連続）
  - 組み合わせ: ボクシングジム（ミット位置の連打）／トラップ＆シュート（方向トラップ→↑シュート）／クレーンゲーム（←→を回数分→↓）／すごろくレース（サイコロの目の回数→↓）／ごうれいマーチ（号令＋「まて！」）
  - タイミング・技: サーフィンライド（方向ごとに拍が違う）／ラリーテニス（←→交互で加速）／フルーツ4レーン（2方向同時押しあり）／ピアノれんしゅう（8分の連続ストリーム）／ひっぱりっこ4ほうこう（方向つき長押し）
- **🎮 アロー版モード**: セレクト画面の「🎮 アロー版」ボタンをONにすると、**アローゲーム以外のすべてのゲーム**（ステージのミニゲーム・リミックス・2人専用40種・エンドレス）のノーツに↑↓←→が付き、その方向のキー（1P=矢印／2P=WASD、または方向パッド）でしか取れなくなります。通常版はOFFに戻せばそのまま。方向はゲームごとに毎回同じ配置（同時押しは別方向）、キャラの上に次の矢印が並んで予告されます。アロー版でクリアすると通常の記録に加えて 🎮 バッジが付き、エンドレスの記録も別枠です。
- **⌨️ キーボード版モード**: 「⌨️ キーボード版」ボタンをONにすると、アローゲーム以外のすべてのゲームのノーツに **A〜Z・0〜9 のキー**が付き、そのキーでしか取れなくなります（キャラの上に次のキーが並んで予告、レーンにも文字表示）。**アローキー(↑↓←→)はレーンの ON/OFF 専用**になります（このモードではLもノーツ用のキー）。2人モードは1P=キーボード左半分（1〜5・Q〜T・A〜G・Z〜B）、2P=右半分（6〜0・Y〜P・H〜L・N・M）。キー配置はゲームごとに毎回同じ、同時押しは別キー、直前と同じキーは避けます。とりあいノーツ（対戦）はキーなし＝どのキーでもOK。アロー版とは同時にONにできません。クリアすると ⌨️ バッジが付き、エンドレスの記録も別枠です。
- **長押しノーツ**（バー付き）: 頭のタイミングで押し、**バーの終わりで離す**（±セーフ幅）。早く離すと「はなすの はやい！」でミス扱い、終わりを過ぎても押していれば自動で成功です。押している間はキャラの上にゲージが出ます。きかんしゃ（汽笛を鳴らし続ける）／ミラクルフラワー（水やり）／ネジまきロボ（回し続ける）／ものまねバード（ロングトーン）に登場し、1人・2人どちらでも遊べます。
- 各ゲームは「合図(キュー)→ 決まった拍の後にボタン」。判定は **ピッタリ / セーフ / ミス**。
- 画面下の**タイミングレーン**: ●のノーツが右から流れてきて、左の◯(わっか)に重なった瞬間がボタンを押すタイミング。わっかは判定結果の色(金/緑/赤)で光ります。裏モードでは●が直前で消えます。
- レーンはセレクト画面の「🎯 レーン」ボタンで表示/非表示を設定でき(保存されます)、**ゲーム中でも Lキー でリアルタイムに切替**できます。
- むやみに連打すると「おてつき」でスコアが減り、さらに**短時間ボタンが効かなくなります**(硬直中に連打すると硬直が延長)。連打では絶対に勝てません。
- 対戦で同点の場合はピッタリ数 → セーフ数 → おてつき+ミスの少なさでタイブレークします。
- スコア **60以上でクリア(✅)**、**85以上でハイレベル(⭐)**。Esc で中断。

## 2人プレイ（協力・対戦）

セレクト画面上部の「あそびかた」で **1人 / ふたり協力 / ふたり対戦** を切り替えられます。

- **操作**: 1P = F/Gキー・アローキー(↑↓←→)・画面左半分タップ（青ノーツ）、2P = J/Kキー・**WASD**(W=↑ A=← S=↓ D=→)・画面右半分タップ（オレンジノーツ）
- **アローゲームも2人で遊べます**（協力・対戦ともにリスト上部に「🎮 アローゲーム」の行）。方向ノーツは1Pが↑↓←→、2PがWASDで取ります。方向パッドは1Pが画面左、2Pが画面右に出ます。クリア記録は1人モードと共通です。
- どのミニゲーム・リミックスも2人で遊べます。ノーツはフレーズ単位で1P/2Pに自動で交互に割り当てられ（枚数は自動バランス）、レーンは1Pが上段・2Pが下段に色分け表示されます。
- **協力**: 2人の合計で1つのスコア → クリア判定。**結果はセーブされ、解放も進みます**（2人でキャンペーン攻略OK）。
- **対戦**: 自分のノーツだけで各自スコアを計算し、高い方の勝ち。結果はセーブされません。

### ふたりせんようミニゲーム（全40種: 協力20 + 対戦20）

協力/対戦モードのときだけ、リストの最上部に専用ゲームが出ます（最初から遊べます）。交互・同時押し・カノン・ポリリズム・裏拍/16分シンコペ・加速・不規則間隔・記憶コピー・ため押し・反応速度・ボム我慢など、リズム構造の異なるメカニクスを揃えています。代表例:

- 🤝 協力: もちつき(交互) / おみこし(同時) / おいかけコーラス(1拍遅れカノン) / たいこコンビ(音の高低で担当分け) / とびいしわたり(不規則な間) / うちゅうドッキング(6拍ため同時) など20種
- ⚔ 対戦: はやどりスター(先取り) / リズムかけっこ(表拍vs裏拍) / DJスクラッチ(16分ずらし) / ふうせんチキンレース(ランダムなパンク時刻ギリギリ狙い) / ビリビリスイッチ(ボム我慢) / エアホッケー(不規則ラリー) など20種

### 音楽の生成

BGMはゲームごとに**ジャンル**（チップチューン／ファンク／ハウス／ボサノバ／ロック／ローファイ／スウィング）を1つ選び、そのジャンルに合ったドラム・ベース・パッド・リード・アルペジオ・ディレイの組を使って固定生成されます。

- **曲の構成**: イントロ（パッド＋アルペジオ）→ A → ブレイク（ドラム抜き）→ B（フル＋パーカッション）と展開し、切り替わりにはライザーとクラッシュが入ります。エンドレスでは8小節ブロックごとに巡ります。
- **和音**: add9 / maj7 / min7 / sus4 / dom7 などテンション入りの進行を6+4種から選択。メロディはモチーフを A → A'（終わりを変奏）→ B → A''（ルートに着地）と展開し、強拍はコードトーンに寄せます。
- **サウンド**: マスターコンプレッサ、テンポ同期ディレイ、リバーブ、ステレオパン（アルペジオ左右振り・スタブの声部広げ）、フィルターエンベロープ付きベース、スーパーソー／オルガン／チップのパッド（キックでダッキング）、FMベル／デチューン矩形波（ポルタメント付き）／フィルターソー／フルート／オルガンのリード。すべて Web Audio のリアルタイム合成で外部素材なし。

## パーフェクトキャンペーン

ゲームをクリアすると、**ときどき（約40%）クリア済みのゲーム1つを指名して「パーフェクトキャンペーン」が開催**されます。セレクト画面の最上部に金色のバナーで告知され、対象ゲームには 🎯 が付きます。

- **ノーミス（ミス0・おてつき0・ボム0）でクリアすれば達成** → そのゲームに 💯 が永久に付き、ヘッダーの `💯 n` が増えます。
- **ミスやおてつきが1つでも出た瞬間、その場で「ざんねん…」と中断**されます（リズム天国と同じ挙動）。
- **チャンスは3回**。使い切るとキャンペーンは終了し、後日また別のゲームで開催されます。達成済みのゲームは二度と対象になりません。
- 対象は **1人モード＝おもてのミニゲーム60本＋アローゲーム20本／協力モード＝協力専用ゲーム20本**（対戦モードは競争のため対象外）。全達成すると 🎊 コンプリート表示が出ます。

### パーフェクト達成後の再挑戦

💯 を取ったゲームをもう一度選ぶと、**「▶ ふつうに あそぶ」／「💯 パーフェクトに ちょうせん」** を選べます。この自由挑戦は何度でもでき、**失敗してもキャンペーンのチャンスは減りません**（💯 の記録もそのまま）。

### 🌙 ナイトモード（かくし要素）

**タイミングレーンを消したまま（🎯 レーン: OFF のまま）パーフェクトを達成する**と、ナイトモードが解放されます。キャンペーン・自由挑戦のどちらでもOKですが、**プレイ中に一度でも L キーでレーンを点けると無効**です。

解放後はセレクト画面の **🌙 ナイト** ボタンでいつでも ON/OFF でき、メニューもゲーム画面も星空の夜バージョン（背景が暗くなり、星が増え、月が浮かぶ）に変わります。裏モードと重ねるとさらに深い闇になります。

## エンドレスリミックス（ぜんぶクリアで解放・モードごとに別物）

各モードの内容を**すべてクリアすると、そのモード専用のエンドレスリミックス**がセレクト画面いちばん下に解放されます。48セクションを生き延びるサバイバルで、**進むほどテンポが上がり続けます**（フル完走で約2分半）。譜面は毎回ランダム生成、記録（ポイント = ピッタリ2点・セーフ1点）はベストが保存されます。ライフは **ミス・おてつき（空振り／方向ちがい／キーちがい）・ボム** のたびに1つ減り、0でその場で終了です。

| モード | 解放条件 | 内容 | ライフ |
|---|---|---|---|
| 🎮 1人 | **おもてステージを全クリア（80本）**。裏は条件に含みません | **エンドレスリミックス ∞** — ソロ12種が延々登場。BPM 126→190 | 3（ミス・おてつき・ボム 3回で終了） |
| 🤝 協力 | 協力ゲーム20種を全クリア | **エンドレス・きずなループ** — 協力20種が延々登場。BPM 118→172 | **ふたりで5つ共有**（どちらのミス・おてつきでも減る） |
| ⚔ 対戦 | 対戦ゲーム20種を全クリア | **エンドレス・サバイバルバトル** — 対戦20種が延々登場。BPM 124→186 | **各自3つ**。先に0になった方の負け |

### 💯 エンドレスのパーフェクトちょうせん

エンドレスのボタンを押すと「♾️ ふつうに あそぶ／💯 パーフェクトで ちょうせん」を選べます。パーフェクトは **ライフが1つだけ**（協力はふたりで共有1つ、対戦は各自1つ＝サドンデス）で、ミス・おてつき・ボムが1つでも出た瞬間に終了。48セクションを生き延びると「💯 エンドレス パーフェクト たっせい！！」になります。ゲーム中はHUDに「💯 パーフェクト」と出て、ベスト記録（ポイント）はふつうのエンドレスとは**別枠**で保存されます（アロー版・キーボード版もそれぞれ別枠）。

### 1ゲームだけのエンドレス（クレーンゲーム）

アローゲームの **🧸 クレーンゲーム** を選ぶと「▶ ふつうに あそぶ／♾️ エンドレスで あそぶ／♾️💯 エンドレスを パーフェクトで」を選べます（1人・協力・対戦すべて）。エンドレス版はクレーンゲームだけが延々と続き、ライフの仕組み（1人3／協力は共有5／対戦は各3）とテンポの上がり方はそのモードのエンドレスと同じで、ベスト記録はゲーム×モードごとに別に保存されます。解放条件はなく、最初から遊べます。

※対戦モードは通常キャンペーンの結果を保存しませんが、**対戦専用ゲーム20種のクリア記録だけ**は残ります（エンドレス解放の判定に使うため）。専用ゲームのボタンには協力・対戦とも ✅ が付き、見出しに `✅ n/20` の進捗が出ます。

解放前は「あと N」と**残っている中身（例: `ステージ12のゲーム2本とリミックス`）**がその場に表示されます。セレクト画面ヘッダーの `✅ n/80` は表示中の面（表／裏）のクリア数です。

## ゲーム構成

- **ステージ1〜15**: ミニゲーム4つ + リミックス。
  - **4つのミニゲームを全部クリアすると、そのステージのリミックスが解放**されます。
  - リミックスをクリアすると次のステージのミニゲーム4つが解放されます。
- **リミックス16〜20 (EXステージ)**: ミニゲームなしのオールスターリミックス。
  - **リミックス15以降は、リミックスをクリアすると次のリミックスが解放**されます (15→16→17→…→20)。
- **裏モード**: **おもての「リミックス8」をクリアすると解放**。
  - セレクト画面右上のボタンで **表⇄裏を切り替え**できます。
  - 裏はテンポアップ + 判定強化 + 飛んでくる物が途中で見えなくなる高難度版で、進行度は表とは別管理です。

ミニゲームは12種類のメカニクス（マーチ / バッティング / ものまね / なわとび / シューター / はくしゅ / カエル / からて / きかんしゃ / フラワー / ロボ / スターキャッチ）が、ステージが進むごとに高難度バージョンで再登場します。譜面はゲームIDから決定的に生成されるので、同じゲームは何度やっても同じ譜面(=練習して覚えられる)です。

## 開発メモ

- セーブは `localStorage`(`miracleStars.save.v1`)。セレクト画面の 🗑 で全消去。
- URL に `#debug` を付けて開くと全ステージ・裏モードが解放されます(動作確認用)。
- 判定窓: 表 ±75ms(ピッタリ)/±150ms(セーフ)、裏 ±58ms/±120ms。
