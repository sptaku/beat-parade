# ドンピシャ！ビートパレード

リズム天国シリーズにインスパイアされた、ブラウザで動く1ボタンリズムゲームです。
外部素材・ライブラリなし。音はすべて Web Audio API でリアルタイム合成で、BGMはドラム+ベースライン+コードパッド+アルペジオ+ベルメロディの5レイヤー+リバーブ(残響)構成。`index.html` をブラウザで開くだけで遊べます。

## 遊び方

- **操作はワンボタン**: スペースキー / J / F / クリック / タップ
- 各ゲームは「合図(キュー)→ 決まった拍の後にボタン」。判定は **ピッタリ / セーフ / ミス**。
- 画面下の**タイミングレーン**: ●のノーツが右から流れてきて、左の◯(わっか)に重なった瞬間がボタンを押すタイミング。わっかは判定結果の色(金/緑/赤)で光ります。裏モードでは●が直前で消えます。
- レーンはセレクト画面の「🎯 レーン」ボタンで表示/非表示を設定でき(保存されます)、**ゲーム中でも Lキー でリアルタイムに切替**できます。
- むやみに連打すると「おてつき」でスコアが減り、さらに**短時間ボタンが効かなくなります**(硬直中に連打すると硬直が延長)。連打では絶対に勝てません。
- 対戦で同点の場合はピッタリ数 → セーフ数 → おてつき+ミスの少なさでタイブレークします。
- スコア **60以上でクリア(✅)**、**85以上でハイレベル(⭐)**。Esc で中断。

## 2人プレイ（協力・対戦）

セレクト画面上部の「あそびかた」で **1人 / ふたり協力 / ふたり対戦** を切り替えられます。

- **操作**: 1P = F/Dキー・画面左半分タップ（青ノーツ）、2P = J/Kキー・画面右半分タップ（オレンジノーツ）
- どのミニゲーム・リミックスも2人で遊べます。ノーツはフレーズ単位で1P/2Pに自動で交互に割り当てられ（枚数は自動バランス）、レーンは1Pが上段・2Pが下段に色分け表示されます。
- **協力**: 2人の合計で1つのスコア → クリア判定。**結果はセーブされ、解放も進みます**（2人でキャンペーン攻略OK）。
- **対戦**: 自分のノーツだけで各自スコアを計算し、高い方の勝ち。結果はセーブされません。

### ふたりせんようミニゲーム（全40種: 協力20 + 対戦20）

協力/対戦モードのときだけ、リストの最上部に専用ゲームが出ます（最初から遊べます）。交互・同時押し・カノン・ポリリズム・裏拍/16分シンコペ・加速・不規則間隔・記憶コピー・ため押し・反応速度・ボム我慢など、リズム構造の異なるメカニクスを揃えています。代表例:

- 🤝 協力: もちつき(交互) / おみこし(同時) / おいかけコーラス(1拍遅れカノン) / たいこコンビ(音の高低で担当分け) / とびいしわたり(不規則な間) / うちゅうドッキング(6拍ため同時) など20種
- ⚔ 対戦: はやどりスター(先取り) / リズムかけっこ(表拍vs裏拍) / DJスクラッチ(16分ずらし) / ふうせんチキンレース(ランダムなパンク時刻ギリギリ狙い) / ビリビリスイッチ(ボム我慢) / エアホッケー(不規則ラリー) など20種

### 音楽の生成

BGMはゲームごとに、コード進行(4〜5種)×リード音色(5種)×スケール(3種)×モチーフ(6リズム型×2)×**ドラムグルーヴ(8ビート/四つ打ち/ハーフタイム/シャッフル/ラテン/ファンク)**×**ベースライン(5型)**×**アルペジオ(4スタイル)**×セブンスコード有無を組み合わせて固定生成されます。

- 🤝 協力限定（5種）
  - **もちつきペッタン**: 1Pが「ぺったん」とついたら、2Pが「こねっ」と返す交互リズム。
  - **おみこしワッショイ**: 合図の2拍後に、2人**同時**にワッショイ！
  - **トスでアタック**: ボールが落ちてきた側がトス、相方が1拍後にアタック。役割は毎回入れ替わる。
  - **ロケットカウントダウン**: 「3・2・1」を交互にカウントして、最後は2人同時押しで発射！
  - **リレーコーラス**: 小鳥のメロディを1P→2Pの順に記憶リレーでまねっこ。
- ⚔ 対戦限定（5種）
  - **はやどりスター**: 中央に流れ星(黄色のとりあいノーツ)。ジャストで先に押した方がゲット。
  - **つなひきリズム**: 笛の1拍半後に引っ張る。ピッタリなら2倍引けて、旗が自分の陣地へ動く。
  - **もぐらたたきバトル**: 自陣のもぐらを叩く。ただし💣ボムを叩くとおてつき2回分の大ダメージ(放置が正解)。
  - **はやうちガンマン**: ランダムなタイミングの「バンッ!」に反応して早撃ち。レーンにノーツが出ない反応勝負。フライングはおてつき。
  - **ピンポンラリー**: 交互に打ち合うラリーが1フレーズ内でどんどん加速。自分の番を逃すな。

## ゲーム構成

- **ステージ1〜15**: ミニゲーム4つ + リミックス。
  - **4つのミニゲームを全部クリアすると、そのステージのリミックスが解放**されます。
  - リミックスをクリアすると次のステージのミニゲーム4つが解放されます。
- **リミックス16〜20 (EXステージ)**: ミニゲームなしのオールスターリミックス。
  - **リミックス15以降は、リミックスをクリアすると次のリミックスが解放**されます (15→16→17→…→20)。
- **裏モード**: **おもての「リミックス8」をクリアすると解放**。
  - セレクト画面右上のボタンで **表⇄裏を切り替え**できます。
  - 裏はテンポアップ + 判定強化 + 飛んでくる物が途中で見えなくなる高難度版で、進行度は表とは別管理です。

ミニゲームは12種類のメカニクス（マーチ / バッティング / ものまね / なわとび / シューター / はくしゅ / カエル / からて / きかんしゃ / フラワー / ロボ / スターキャッチ）が、ステージが進むごとに高難度バージョンで再登場します。譜面はゲームIDから決定的に生成されるので、同じゲームは何度やっても同じ譜面(=練習して覚えられる)です。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 画面の骨組み |
| `css/style.css` | 見た目(表/裏テーマ切替含む) |
| `js/audio.js` | Web Audio 合成(BGM・効果音・ジングル) |
| `js/patterns.js` | 12種のミニゲーム定義(譜面生成 + Canvas描画) |
| `js/data.js` | ステージ構成・解放条件・セーブ(localStorage) |
| `js/engine.js` | コンダクター(音声クロック同期)・判定・描画ループ |
| `js/ui.js` | タイトル / セレクト / リザルト画面 |

## 開発メモ

- セーブは `localStorage`(`miracleStars.save.v1`)。セレクト画面の 🗑 で全消去。
- URL に `#debug` を付けて開くと全ステージ・裏モードが解放されます(動作確認用)。
- 判定窓: 表 ±75ms(ピッタリ)/±150ms(セーフ)、裏 ±58ms/±120ms。
